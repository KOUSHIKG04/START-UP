## Missing management surfaces justified by existing data

- Clinic owner setup and active-practice selector; must work when the doctor is the only member.
- Invite/revoke staff and scope reception to doctor practices. Existing organization_member/member_doctor_scope require usable management, not a generic all-powerful role editor.
- Appointment request details, reasons and proposed time response; walk-in registration/manual check-in with audit reason; queue call/hold/no-show controls.
- Inventory update with observation time, maintenance and conflicting-edit recovery. Patient public projection must label report freshness and must not promise admission.
- Department/duty roster management, if Figma roster stays in current scope; cannot be implemented as a duplicate doctor availability calendar.
- Credential reviewer operations are needed before verification can be live, even though platform console is deferred. OPEN: who performs these reviews in the interim and how they receive least-privilege access.

## Full portal action chains

**Update inventory:** select facility → edit total/occupied/maintenance → authenticated scoped update(expected version) → count invariant and membership validation → inventory/audit/domain event commit → portal refetch. The database command and shared adapter now exist and passed disposable tests; the portal is still local-state only. Patient/dispatcher public projections and freshness policy remain open.

**Associate doctor:** search registered doctor → propose affiliation/invitation → permitted facility administrator → intended doctor accepts/verification process approves → doctor_facility and services → doctor practice selector and patient directory. No creation of a second unrelated profile based on same display name.

**Reception operations:** select authorized practice → find/book/check-in patient → minimal operational DTO → authorized atomic command → appointment/check-in/queue event → doctor and patient refresh. Reception sees scheduling/contact data necessary for the task, not unrestricted notes/prescriptions.

## Deferred platform console

Figma has global patients/doctors/ambulances, Live SOS Command Center, credential review, reports, role/security settings and authenticator MFA (`717:8`). These are documented requirements for a later console, not permission grants to current hospital users. Platform-wide audit/export/finance privileges must never be inferred from `organization_member.role=owner`.
